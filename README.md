# Sprint_6
# Самокат — UI-тестирование

Автоматизированное тестирование веб-приложения «Самокат» (https://qa-scooter.praktikum-services.ru/) с использованием Python, Selenium WebDriver, pytest и Allure.

## О проекте

В рамках проекта проведена автоматизация функционального тестирования основных пользовательских сценариев веб-приложения:

- оформление заказа через верхнюю и нижнюю кнопки «Заказать»;
- заполнение формы заказа;
- проверка успешного оформления заказа;
- проверка работы выпадающего списка вопросов и ответов;
- проверка перехода на главную страницу по логотипу «Самокат»;
- проверка перехода на сайт Дзена по логотипу Яндекса.

Автотесты написаны на Python с использованием Selenium WebDriver и pytest. Для структурирования тестов и формирования отчётов используется Allure.

## Что протестировано

### Выпадающий список вопросов

Проверено раскрытие ответов на часто задаваемые вопросы при нажатии на соответствующие элементы списка.

### Оформление заказа

Проверены сценарии оформления заказа через две кнопки:

- верхнюю кнопку «Заказать»;
- нижнюю кнопку «Заказать».

Для каждого сценария проверены:

- заполнение персональных данных;
- выбор станции метро;
- заполнение данных об аренде;
- подтверждение заказа;
- отображение сообщения об успешном оформлении заказа.

### Логотипы

Проверены переходы при нажатии на логотипы с главной страницы:

- логотип «Самокат» — переход на главную страницу;
- логотип Яндекса — открытие сайта Дзена в новой вкладке.

## Архитектура автотестов

В проекте используется паттерн Page Object Model.

- `pages/` — классы страниц и методы взаимодействия с элементами;
- `locators/` — локаторы элементов страниц;
- `tests/` — тестовые сценарии;
- `conftest.py` — фикстуры pytest и настройка WebDriver;
- `utils.py` — вспомогательные методы и тестовые данные;
- `urls.py` — URL приложения.

Общие действия с элементами страницы вынесены в базовый класс `BasePage`.

## Отчёты Allure

Для разметки тестов используются декораторы Allure:

- `@allure.feature` — группировка тестов по функциональности;
- `@allure.title` — название тестового сценария;
- `@allure.step` — описание шагов выполнения теста.

Результаты тестирования сохраняются в формате Allure.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest
```

## Формирование отчёта Allure

Запуск тестов с сохранением результатов:

```bash
pytest --alluredir=allure_results
```

Просмотр отчёта:

```bash
allure serve allure_results
```
